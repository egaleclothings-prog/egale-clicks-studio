# EGALE CLICKS STUDIO Website

A responsive black-and-gold photography and videography website.

## Included
- `index.html` — website content and booking form
- `style.css` — responsive black-and-gold design
- `script.js` — mobile navigation, city-specific famous places, WhatsApp enquiry

## Publish on GitHub Pages
1. Open your repository: `egaleclothings-pro/egale-clicks-studio`.
2. Upload/replace these three files at the repository root: `index.html`, `style.css`, `script.js`.
3. Commit the changes to the `main` branch.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then Save.
6. Wait a few minutes. Your Pages URL will be shown in that same section.

The WhatsApp number is set in `script.js` to `918147764411`. Update it only if you want enquiries sent to a different WhatsApp number.
